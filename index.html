About EVD

Operator tooling for institutional finance

Ellari Ventures Development (EVD) builds software infrastructure for small business operators pursuing institutional financing — including SBA 7(a) loans, franchise acquisition financing, and succession planning. Our tools are designed for operators, their guarantors, and the lenders and advisors who serve them.

EVD products are built on Cloudflare's infrastructure (Pages, Workers, D1) and deployed under Caretide Systems LLC and Sigwell LLC as operating entities. All financial data integrations are implemented with read-only access, explicit user consent, and strict data minimization principles.

Products using financial data APIs

Platform overview

The following EVD products connect to financial data APIs to serve operators in loan preparation workflows.

FranchiseDash
SBA Loan Preparation · Plaid API

FranchiseDash is an SBA loan preparation platform for franchise operators and their guarantors. The platform helps operators assemble the full SBA 7(a) documentation package — including Personal Financial Statements (SBA Form 413), construction bid analysis, risk registers, and lender communication logs — through a structured, role-based workflow.

Plaid integration: Guarantors may optionally connect bank, brokerage, and retirement accounts via Plaid Link to import live account balances directly into their Form 413 asset schedule. This replaces manual balance entry with institution-verified data, improving accuracy and reducing document turnaround time for lenders. Connection is per-session, user-initiated, and fully revocable.

Data policy

Commitments

  • ✓ Read-only access. We request balance data only. We do not initiate transactions, move funds, or write to any financial account.
  • ✓ Explicit user consent. Each guarantor initiates their own Plaid Link connection. No connections are made without active user action.
  • ✓ No third-party sharing. Financial data is never sold, shared with marketing platforms, or disclosed to any party other than the lender as part of the SBA package the user is actively assembling.
  • ✓ No cross-product use. Data imported via Plaid in FranchiseDash is scoped to that deal workflow. It is not used by other EVD products.
  • ✓ User-controlled deletion. Guarantors may disconnect their institution and delete their imported data at any time from the PFS Assets interface.
  • ✓ Encrypted at rest. All data is stored in Cloudflare D1 with encryption at rest. Access is controlled via Cloudflare Zero Trust (CF Access) with per-role authentication.
  • ✓ Sandbox environment. All development and testing uses Plaid's sandbox environment with synthetic data. No real financial credentials are used outside production.
